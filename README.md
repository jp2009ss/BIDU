# Bidu

Plataforma de passeios para pets com acompanhamento ao vivo. O Bidu conecta tutores a cuidadores treinados, garantindo segurança e transparência durante todo o trajeto.

## Funcionalidades
- **Rastreio em tempo real:** Acompanhe o passeio do seu pet no mapa, do início ao fim.
- **Cuidadores verificados:** Profissionais treinados e avaliados.
- **Lista de espera:** Gerenciamento de interessados para o lançamento.
- **Interface responsiva:** Otimizado para desktop e mobile.

## Tecnologias
- HTML5 / CSS3
- JavaScript (Vanilla)
- SVG Animations (Map route & Tracking)

## Como rodar localmente
1. Clone o repositório.
2. Abra o arquivo `index.html` diretamente no seu navegador.
